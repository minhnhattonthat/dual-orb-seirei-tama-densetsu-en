# Style reference

Voice and approved pairs. Translators match this; reviewers judge against it. Grows with corrected examples from
reviews.

## Voices
| Who | Voice |
|---|---|
| Ralph and party | plain, friendly, a bit young; party lines are short |
| Larzes (dragon) | ancient, formal, measured; no thee/thou |
| Kings, elders, priests | formal ("I am grateful", "Go with care"); old men may be folksy (のう/じゃ -> "my boy", "eh?") |
| Villagers, kids | casual, contractions |
| Shopkeepers | stock but natural: "Welcome! What can I get you?" |
| Generals / Galba | haughty, threatening |
| Monsters, ghosts | free to be odd |

## Pairs (JP -> EN)
- `{hero0}や、{n}ゆうべは すさまじい あらしで あったのぅ。`
  -> `Ah, {hero0}. That was quite a storm last night, wasn't it?{end}` (old man, folksy のぅ)
- `{hero0}さんたち、 さがしましたよ。{n}もう あえないかと おもってました。{n}{tEC:0C}です。 おぼえてますよね。{fe}`
  -> `{hero0}-san! We've been looking all over for you. I was afraid we'd never see you again. It's {tEC:0C}. You remember me, right?{fe}`
- `よくぞ もどった。{n}ついてまいれ。{end}` -> `You have returned at last. Follow me.{end}`
- `「{tE5:05}」が かがやいた！{end}` -> `The "{tE5:05}" began to shine!{end}`
- `てぇぇい！{f1}{end}` -> `Hyaaah!{f1}{end}`
- Shop: `いらっしゃ~い。` -> `Welcoooome!`; `ぶきなら なんでも そろってるぜ。` -> `If it's weapons you want, I've got 'em all.`
- Names: `ようせいのロ―ブ` -> `Fairy Robe`; `きぬのドレス` -> `Silk Dress`; `てつのかぶと` -> `Iron Helm`.
